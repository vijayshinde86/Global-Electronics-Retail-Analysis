# Global Electronics Retail Analysis

## Project Overview

This is a Data Analytics project focused on analyzing global electronics retail sales data to identify business trends, sales performance, and actionable insights.

## Project Objectives

* Analyze overall sales and profit performance.
* Identify top-performing products and categories.
* Analyze customer purchasing patterns.
* Compare sales across countries and stores.
* Understand sales trends over time.
* Create an interactive Power BI dashboard.

## Tools & Technologies

* Python
* Pandas
* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Microsoft Power BI
* DAX

## Project Workflow

1. Raw Dataset Collection
2. Data Preprocessing using Python
3. Exploratory Data Analysis
4. Data Modeling
5. Power BI Dashboard Development
6. Business Insights and Recommendations

## Key Analysis Areas

* Total Revenue
* Total Profit
* Total Orders
* Quantity Sold
* Product and Category Performance
* Customer Analysis
* Country and Store Performance
* Sales Trends

## Project Structure

* `data/` — Dataset files
* `preprocessing/` — Python preprocessing scripts
* `powerbi/` — Power BI dashboard files
* `reports/` — Project reports

## Project Goal

The goal is to transform raw retail data into meaningful business insights that support better decision-making.
